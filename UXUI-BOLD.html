01 แยกสี่อย่างออกจากกัน

สิ่งที่เห็นในภาพรับได้ไหมเพราะ
การ์ดยกพื้น มีขอบมน แทนแถวคั่นเส้น รับเลย ไม่ขัดกฎอะไร และทำให้แตะง่ายขึ้นบนมือถือ — พื้นที่แตะใหญ่ขึ้นราวเท่าตัว
ไอคอนสี่เหลี่ยมมนสีสดหน้าแถว ต้องดัด ในภาพสีไอคอนไม่มีความหมาย เป็นแค่การไล่สีให้สวย · ที่นี่ทุกสีมีความหมายผูกไว้แล้ว ต้องให้สีไอคอนตรงกับชนิดของข้อมูล ไม่ใช่ไล่ตามลำดับ
หัวข้อใหญ่ตัวหนา มีคำเน้นไล่สี รับเลย ตอนนี้หัวหน้าวันนี้เป็นแค่วันที่ตัวเล็ก · การมีประโยคที่บอกว่า “วันนี้ต้องสนใจอะไร” ทำงานแทน hero ได้เลย
แถบล่างมีไอคอน รับเลย ตอนนี้เป็นข้อความล้วนห้าช่อง ซึ่งบนจอ 360px ตัวอักษรเล็กจนอ่านยาก · ไอคอนช่วยให้จำตำแหน่งได้โดยไม่ต้องอ่าน
ช่องถามลอยอยู่ล่างทุกหน้า ไม่รับ แท็บ KeviN มีอยู่แล้วและอยู่กลางแถบล่าง · ใส่ช่องถามซ้ำอีกจะมีสองทางไปที่เดียวกัน และกินที่ถาวรจากเนื้อหา

03 ไอคอนสี — จุดเดียวที่ต้องดัด

ในภาพอ้างอิง ไอคอนสามใบเป็นม่วง ฟ้า ชมพู ไล่ลงมาสวยงาม แต่สีนั้นไม่ได้บอกอะไรเลย — สลับที่กันก็ยังสวยเหมือนเดิม

ที่นี่ทำแบบนั้นไม่ได้ เพราะกฎข้อเดียวของแอปคือ ม่วงคือสิ่งที่กดได้ สีที่เหลือคือข้อมูล ถ้าไอคอนไล่สีสวย ๆ กฎนั้นตายทันที · ทางออกคือให้สีไอคอนมาจากชนิดของข้อมูล ที่กำหนดไว้อยู่แล้ว — ได้ความสดมาโดยไม่เสียความหมาย

ผลพลอยได้ที่ไม่ได้ตั้งใจ — พอไอคอนมีสีตามชนิด แถบสีบางด้านซ้ายก็ไม่ต้องมีแล้ว เพราะมันบอกเรื่องเดียวกัน แถวจึงสะอาดขึ้นทั้งที่ข้อมูลเท่าเดิม
สิ่งที่ต้องระวัง — ไอคอนต้องต่างกันด้วยรูป ไม่ใช่แค่สี คนตาบอดสีจะเห็นสี่เหลี่ยมเทาเหมือนกันหมด · นาฬิกา = คาบ · เครื่องหมายถูก = งาน · วงกลมอัศเจรีย์ = เลยกำหนด

04 “คุยล่าสุด” — ของที่มีอยู่แล้วแต่ไม่เคยได้ใช้

ส่วนที่น่าสนใจที่สุดในภาพอ้างอิงคือ Recent conversations — เพราะตอนนี้ใน DB มีบทสนทนา 17 รายการ เก็บไว้ครบทั้งข้อความและ tool ที่เรียก แต่ไม่มีหน้าไหนเปิดดูได้เลย

ตารางถูกสร้างตอนทำประตูที่สาม พร้อม index conversations_recent ที่เรียงตามเวลาให้แล้ว — ของพร้อมใช้ ขาดแค่ที่แสดง

ทำอะไรต้นทุนได้อะไร
โชว์ 2 บทสนทนาล่าสุดในหน้าวันนี้ query เดียว · ใช้ index ที่มีอยู่ กลับไปคุยต่อจากที่ค้างไว้ได้โดยไม่ต้องเข้าแท็บ KeviN แล้วเลื่อนหา
หน้า /kevin/history หน้าใหม่หนึ่งหน้า ย้อนดูว่าเคยถามอะไรไปแล้ว · ตอนนี้ประวัติหายไปกับตาทุกครั้งที่ปิดแอป

05 สิ่งที่ตั้งใจไม่รับมา

ในภาพทำไมไม่รับ
ช่องถามลอยล่างทุกหน้า แท็บ KeviN อยู่กลางแถบล่างอยู่แล้ว · มีสองทางไปที่เดียวกันทำให้ต้องคิดว่าจะใช้ทางไหน ทั้งที่ผลเหมือนกัน
ทุกการ์ดหน้าตาเท่ากัน ข้อสำคัญที่สุด — ของที่เลยกำหนดกับของที่ยังไม่ถึงเวลาต้องดูไม่เท่ากัน ไม่งั้นการจัดลำดับความสำคัญที่ทำมาทั้งหมดหายไปกับความสวย
ทักทาย “สวัสดีตอนเช้า, ชื่อ” เก็บไว้แต่ย่อลงเป็นบรรทัดเล็กคู่กับวันที่ · ผู้ใช้คนเดียวที่รู้ชื่อตัวเองอยู่แล้ว การทักทายเต็มบรรทัดกินที่ของข้อมูลจริง
พื้นหลังม่วงอิ่มกว่าเดิม รับมาเล็กน้อย (#0A0912 → #120E22) พอให้อุ่นขึ้นแต่ยังอ่านกลางแดดได้ · อิ่มกว่านี้คอนทราสต์จะตกจนตัวอักษรสีจางอ่านไม่ออกนอกห้อง

06 ลำดับการทำ

ขั้นทำอะไรกระทบกี่หน้า
1แถบล่างใส่ไอคอนทุกหน้า · แต่แก้ไฟล์เดียว (Nav.tsx)
2แถวกลายเป็นการ์ด + ไอคอนสีตามชนิดItemList.tsx ไฟล์เดียว ทุกหน้าที่ใช้มันได้ตาม
3หัวจอหน้าวันนี้เป็นประโยค + ปุ่มบนหน้าวันนี้
4“คุยล่าสุด” ในหน้าวันนี้หน้าวันนี้ + query เดียว
5พื้นหลังอุ่นขึ้นนิดเดียวtoken เดียวใน globals.css
ขั้น 2 คือขั้นที่คุ้มที่สุด — ItemList ถูกใช้ในหน้าวันนี้ หน้าวิชา หน้ากิจกรรม และหน้าคลังของเก่า · แก้ที่เดียวเปลี่ยนทั้งแอป และ FLIP กับแถบเลิกทำที่ทำไว้แล้วยังทำงานเหมือนเดิมเพราะไม่ได้แตะตรรกะ

ไฟล์นี้เป็นข้อเสนอ ยังไม่ได้ลงมือ · คู่กับ UXUI.html ที่เป็นภาษาภาพปัจจุบัน
